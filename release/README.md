# NEVERWIN — release

Готовые сборки: DLL + инжектор. Правило версий простое: **чем больше число в
приписке `vN`, тем новее сборка**. Первая сборка — `v1`, следующая — `v2`,
и так далее. Старые версии не удаляются, лежат рядом для истории.

## Что лежит

| Файл | Что это |
|---|---|
| `neverwin_vN.dll` | внутренняя DLL (x64 Release, статический рантайм, без рендерного кода) |
| `neverwin_injector_vN.exe` | инжектор |
| `neverwin_overlay_vN.exe` | внешнее меню/HUD на DirectX 12 (не инжектится) |
| `neverwin.ini` | оффсеты от последнего дампа (если сгенерирован) — DLL читает его при инжекте |

## Бинды

**P** — открыть/закрыть меню · F1 реверс аимбот · F2 антиаимлесс · F3 visual
recoil · F4 антибхоп · F5 gamesense · F6 скрыть/показать HUD · END — выгрузка.

## Меню (v5+)

Меню рисует сама DLL **в игре**, по схеме quintcs2: хук на настоящем свопчейне
игры (сигнатура в rendersystemdx11.dll + MinHook), ImGui в бэкбуфер, мышь
освобождается хуком InputSystem::IsRelativeMouseMode. Открытие — **P** или
**INSERT**. Никаких dummy-свопчейнов, из-за которых крашились старые версии.

Не встал рендер-хук (Vulkan / патч Valve сменил сигнатуру) — меню берёт на
себя `neverwin_overlay_vN.exe` (DirectX 12, снаружи игры), он же всегда
показывает HUD. Запускай его до или после инжекта — без разницы.

Игра должна быть в оконном/borderless-режиме (это требование оверлея-фолбэка;
внутриигровому меню всё равно).

Если что-то не так: `%TEMP%\neverwin.log` — там видно, какой шаг меню
отвалился (свопчейн / MinHook / InputSystem / WndProc).

## Реверс аим (v10+)

**F1** циклит: выкл → `raimv1` → `raimv2` → выкл (в меню — комбо).

- `raimv1` — прямая запись `dwViewAngles`;
- `raimv2` — запись в юзеркоманду (раскладка протобуфа velocity/quint решается
  рантайм-пробой, подстраховка прямой записью).

Обе версии: наводка на ближайшего тиммейта **через стены, без лимита дальности**,
живой предпочтительнее трупа.

v10 фикс: `m_iTeamNum` — **uint8**, а мы читали его как int (4 байта). У части
павнов байт после команды ненулевой, и `localTeam` превращался в мусор:
F2 («враг виден») на мусоре срабатывал на всех, а фильтр тиммейтов — ни на ком.
Скан расширен до 512 хэндлов. Диагностика в `%TEMP%\neverwin.log` раз в 5 сек:
`raimvN: цель не найдена. скан 512: павнов X, врагов Y, тиммейтов T (нод N,
origin O), localTeam=L` — по числам видно, где рвётся, если опять рвётся.

`neverwin.ini` общий для всех версий в этой папке: DLL ищет его рядом с собой.
Нет ini — DLL работает на встроенных оффсетах (и почти наверняка они стухшие,
если CS2 обновилась).

## Обновить оффсеты после патча Valve

1. Сними дамп: cs2-dumper с запущенной CS2 → папка `output/`.
2. Сгенерируй ini:
   ```
   python neverwin-internal/tools/dump_to_ini.py "C:\путь\к\output" "C:\папка с DLL\neverwin.ini"
   ```
3. Положи `neverwin.ini` в эту папку (рядом с DLL). Пересобирать DLL не нужно.
   Хочешь обновить и встроенные оффсеты в коде — `neverwin-internal/src/offsets.hpp`.

## Сборка релиза

- **Windows (VS2022):** `release\build_release.bat` — или `build_release.bat 3` для явной версии 3.
- **Linux (кросс, zig):** `bash release/build_release.sh` — версия автоинкрементится.

Обе сборки кладут результат сюда с правильной припиской `vN`.
